# Security Policy

## Reporting a vulnerability

Please do not disclose a security vulnerability in a public issue. Use the repository's **Security** tab to open a private security advisory with:

- the affected version and component;
- clear reproduction steps;
- the expected security impact;
- any suggested remediation, if available.

Do not include real API keys, CVs, account data, or other personal information in a report. Replace secrets and user content with safe test values.

## Scope

Security reports are especially useful for permission misuse, credential exposure, unsafe HTML rendering, unintended data transfer, remote-code execution, or bypasses of the allowed AI-host controls.
